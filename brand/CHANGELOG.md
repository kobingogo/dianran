# 点染 Dianran 更新日志

> 这里是点染自己的版本记录，构建时打包进前端「版本」弹窗。上游 infinite-canvas 的历史见仓库根目录的 `CHANGELOG.md`。

## v1.2.0 - 2026-10-04

+ [新增] 提示词库「X 热门」：从 X 上近两个月（8/4–10/4）的公开帖子中按点赞数人工精选 100 条生图 / 视频提示词，封面存放在本站，详情页显示作者、模型、发布日期和原帖链接。
+ [调整] Banana Prompt Quicker 与 Awesome GPT Image 里原本放在 X / 论坛上的封面也转存到了本站；原帖已删除的、上游标为 NSFW 的，以及没有封面的条目（含点染精选里的纯文字条目）都已从提示词库移除。
+ [新增] 首页「从模板开始」：活动海报、产品图组、四格分镜、情绪板、社媒封面 5 个起步画布，打开即是排好版的文案 + 生成配置，不含任何图片。
+ [新增] 不支持 Responses 接口的服务商（硅基流动、OpenRouter 等）自动改走 /chat/completions；生图按服务商走对应接口，接口返回 404 / 不支持时自动回退。
+ [调整] 所有报错提示统一成中文说明和下一步建议，服务商原始报错只放在可展开的「详情」里。
+ [调整] 提示词库封面图改为站内自带的压缩副本，不再从 GitHub 等外部图床加载；无法转存的封面显示本地占位图。
+ [调整] 画布里的任务中心移到右上角，不再挡住左侧面板和底部工具栏。
+ [调整] 画布 Agent 面板默认关闭，并记住你上次是开还是关。
+ [优化] 手机端（390px 宽）适配：首页、配置向导、设置和画布不再横向溢出，顶栏收进菜单，画布支持双指缩放，侧栏改为覆盖式抽屉。

## v1.1.0 - 2026-10-04

+ [新增] 首次使用向导：选服务商 → 填 API Key → 自动读取模型并按生图 / 视频 / 文本 / 音频分类、设好默认模型；没有可用服务时点生成也会直接打开向导。
+ [新增] 预置常用服务商（OpenAI 兼容中转、OpenAI、Gemini、硅基流动、OpenRouter），只预置接口地址，不含任何 Key。
+ [新增] 任务中心：左下角实时显示生成任务的真实状态（已提交 / 排队中 / 生成中 / 接收中 / 完成 / 失败）和用时，视频任务会显示服务商返回的真实进度。
+ [新增] 常见错误翻译成中文并给出下一步：Key 无效、余额不足、限流、跨域（提示开启本地代理）、超时、模型不存在、内容审核。
+ [新增] 画布里按 ? 打开快捷键面板。
+ [调整] 顶栏精简：插件、快捷键、语言、配置向导、更新日志收进「更多」菜单。
+ [调整] 设置分为「常用」（模型服务、默认模型）和「高级」（本地代理、提示词来源、WebDAV、本地存储）。
+ [调整] 统一叫法：画布、生图、视频、提示词、素材、设置。
+ [调整] 提示词库改为站内自带的副本，并新增「点染精选」，不再在后台请求 GitHub。
+ [优化] 按页面拆分代码，首屏脚本从 3.7 MB 降到约 1.2 MB（gzip 后约 400 KB）。
+ [调整] 本地代理和本地 Agent 改用 @kobinflow/canvas-proxy、@kobinflow/canvas-agent。
