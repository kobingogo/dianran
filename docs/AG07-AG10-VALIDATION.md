# AG07–AG10 本机 Agent 媒体接入验收

## 已实现的共同层

- 独立媒体协议版本 1，与 Agent 通信版本及消息历史存储版本分别管理。
- 统一 Agent/工具/后端/费用来源和文生图、图片编辑、文生视频、图生视频能力描述；未知能力不等于连接成功；Codex 适配器未声明原生视频能力。
- 原意图包含 requestId、原项目、修订、提示词、授权参考原文件及 Agent 身份。持久化成功后才启动任务；同意图并发请求原子认领一次，不声称底层服务提供幂等生成。
- threadId/turnId 绑定任务，itemId 绑定产物，注册时验证原生身份与授权生产目录 realpath；指向目录外的符号链接不能读取。
- 原产物保存只读副本，以 opaque ID 读取，验证 SHA256 与 `file-type` 实际媒体类型；查询返回内容不包含本机生产目录与副本路径。
- 服务重启保留未确认任务为 unknown，不重新生成。记录未知版本/损坏拒绝覆盖；媒体记录独立于消息历史，无历史数据迁移。
- 浏览器任务与导入回执存 localforage，全局 store 受业务写锁保护；本地任务与文件保存失败不触发再次生成。
- 外部 MCP `media_register_artifact` 必须携带读取返回的 target 与原生产物身份；网页专属授权弹窗确认后，后端校验 executing 请求、原项目与完整输入，再读取用户批准目录内原图。直接调用、输入篡改、路径越界拒绝；重复登记保持一份产物。
- 生图任务明确选择 `codexModel`，提交前按当前账户只读模型列表核验；未列出的模型或未选择模型拒绝提交，不自动使用默认模型或回退 API。模型字段原样传入原生 turn。
- 第二 Agent 隔离替身以相同契约验证图片和异步视频登记、查询、读取；Grok Build 尚未接入，不展示为已可用渠道。

## 行为验证

```bash
canvas-agent/node_modules/.bin/tsx --test canvas-agent/src/agent/media-registry.test.ts canvas-agent/src/server/media-routes.test.ts canvas-agent/src/server/http-ag.test.ts
```

13 项通过（包含 3 个原生输出安全子场景）：

1. 错误线程/项目、目录越界/符号链接拒绝；重放不重复；原生文件改变仍读取原副本。
2. 重启未知状态保留；未知版本原记录不覆盖。
3. 未验证工具不提交；视频不可用；明确允许能力验证的同一意图并发只提交一次。
4. 第二 Agent 图片和异步视频经共同契约登记、查询、读取。

5. 原生事件替身等待绑定持久化，登记产物仍归属于原项目。

6. 隔离 HTTP 提交验证项目修订及账户模型清单，能力不虚构视频，错误项目与任意产物 ID 拒绝读取；原生运行时原样保留模型选择。

7. 已有侧栏 turn 显式登记原项目，完成事件等待登记且不启动新的生成。

8. 完整隔离 HTTP 保持令牌认证，过期交互/审批拒绝；画布变更需 claim → validate → 回执，未领取直接回执拒绝，终态可独立查询；外部登记未授权、输入改变、目录越界拒绝，重复登记同一产物。

9. 固定原生输出复制到任务授权目录，原文件删除后仍可读取登记副本；成功登记清除提交阶段旧错误。
10. 拒绝任意路径、文件符号链接和线程目录符号链接，失败保留 unknown 与原任务。

锁定 `@openai/codex@0.146.0` 生成的 schema 存在 imageGeneration item（id/result/status/savedPath/revisedPrompt）；该字段只证明协议能承接事件，不证明当前账户拥有工具。真实调用由总体集成验证执行，本模块测试不消耗生成额度。

## 原生输出目录与真实验证

运行时优先接受当前任务真实授权生产目录内的原图。Codex 若写入固定目录，仅接受 `${CODEX_HOME}/generated_images/<threadId>/<itemId>.png` 精确路径；线程和产物身份必须为安全单段名称，文件、线程目录及 generated_images 目录不得为符号链接，实际目录须与批准位置一致。先复制到任务授权目录，再验证实际类型、登记 SHA256 并保存独立副本，不扩大为任意本机路径读取。普通侧栏使用原任务 cwd，专用生图任务使用独立项目/请求目录。
