# 跨页面创作交互首轮实施

本轮依据 [跨页面规则](./CREATION-INTERACTION-RULES.md) 和 [图片原型](http://127.0.0.1:8766/image-workbench-ux-prototype.html) 修改现有组件与存储，保留纸面主题、浏览器本地作品和原生 Codex 回执。没有修改 Agent 消息协议、生成并发上限、轮询间隔或超时边界。

## 已落地的可测试行为

| 范围 | 变化 |
| --- | --- |
| 任务中心 | 显式业务任务使用 localforage；网络观测不再重复登记同类型业务请求。生成阶段、保存阶段分别显示；清除只隐藏结束展示，未知与未完成保存保留。返回入口携带任务与节点身份。 |
| 图片工作台 | 本机任务在结果区显示占位、原比例图片及下载/参考/素材/画布动作，离线读取已保存原图。历史同时收录 API 与本机记录，并可筛选来源；缺少回执的意图可查询原请求。 |
| 草稿与历史 | 本机/视频收到并保存回执后处理原草稿；同步图片确认输出并保存后处理。下一轮草稿已改变则保留。画布新建草稿按任务处理，已有配置继续保留输入；历史预览不修改草稿与模型，复用条件单独确认。 |
| 视频 | 多个恢复任务独立更新卡片，取状态与重试保存使用原身份。播放作品先显示；保存失败不转成生成失败。停止等待只终止本地查询，远端可能继续；返回后可查询原任务。 |
| 画布 | 控制器与业务任务绑定，输出节点及候选状态不再读取全局最新同类请求；复制节点移除任务关联。任务返回时定位具体节点。图片/视频文件保存失败保留作品，选中节点提供保存重试。 |
| 继续创作与布局 | 生成完成及自动送入画布后保持当前页面；跨模式替换草稿须确认。连接表单优先、安装教程折叠；图片结果窄屏单列，预览保持原比例，状态区提供辅助技术提示。 |

图片 API 没有异步任务回执时，不能在未知受理阶段清空输入；需等待结果确认与保存。未知且没有任务 ID 的请求仍无法自动确认，UI 不将重新生成称为恢复。

画布图片批次用一个业务任务绑定整个结果节点，候选本身仍保留各自的状态和产物 ID。任务中心显示批次级阶段，候选失败需在原节点查看；不宣称渠道提供了逐张百分比。

## 画布本机 Codex 入口

画布底部复合输入框复用本机模型菜单，读取当前画布的独立草稿并展开图片与文字参考；受理后只清空没有新编辑的本轮草稿。提交时在当前视口创建带任务身份的进度节点，第一张产物原位回填，其他产物独立落图。任务意图持久保存目标项目与节点，任务中心返回同一画布；重连及手动查询仅查询原请求，保存失败仅重试导入。原生图片参数由提示词描述，视频仍使用原 API 渠道。

`canvas-local-image.test.mjs`、`agent-media-import.test.mjs`、`agent-media-receipts.test.mjs` 共 10 项行为测试通过，覆盖画布草稿/参考提交、目标位置与修订、草稿清空范围、原位回填、保存去重及刷新后任务定位。真实 Codex 生图和浏览器交互尚待用户验收。

## 验证证据与限制

- `web/tests/creation-task-lifecycle.test.mjs`：并发任务隔离、活动任务刷新为未知、保存与展示清除分离、损坏存储拒绝覆盖、迟到回执保护新草稿。
- `web/tests/agent-media-receipts.test.mjs`、`agent-media-import.test.mjs`：意图与回执持久化、原项目落图、保存重试去重、产物校验（多页面排他编辑保护现已按用户要求停用）。
- `web/tests/agent-media-panel.test.mjs`：离线回执、历史与具体任务选择、助手不重复提供提交界面。
- `web/tests/video-result-save.test.mjs`：下载保存失败不静默冒充本地保存，保存重试复用原输出而不生成。
- 上述 16 项行为用例通过。独立本地浏览器已打开图片历史筛选、视频工作台与空白画布；未执行构建或类型检查，未发布本轮版本，未新增真实付费生成。

## 待实机验收

| 场景 | 需确认的结果 |
| --- | --- |
| 本机文生图/参考编辑 | 受理后草稿处理、原位占位变作品、任务中心与历史对应同一任务；断开服务后保存原图仍可下载。 |
| 已配置视频渠道 | 回执保存后处理草稿；两项活动任务各自恢复；停止等待、切页返回及刷新只取原 ID。 |
| 画布新建/已有配置/候选重试 | 新建草稿处理而配置输入保留，返回精确节点；部分成功候选保留，候选批次不串用另一个任务的状态。 |
| 文件/历史/画布交付失败 | 作品继续可见、失败范围明确；重试只补保存或交付，不再提交模型。 |
| 历史与新草稿同时存在 | 预览旧作品不覆盖新输入；确认复用后才替换；背景完成不抢页签或焦点。 |
| 手机、浅深主题、辅助技术 | 键盘弹出后模型和提交入口可见；作品动作可触达，状态不只依赖颜色。 |

真实输出和故障模拟分别记录；通过后再更新正式功能说明。本轮没有承诺云同步或视频原生 Codex 能力。
