## 可测试入口

- 首页／工作台／画布共用 Composer 的「预设」：保存名称及本模式参数；应用时默认保留当前模型，能力校验后展开参数，调整反馈可见。无 Key、附件或提示词，不自动执行。
- 画布「工作流」→「本机模板」：ZIP 包含白名单计划和本机原始文件；导入追加模板、重新分配文件身份，展开为独立节点。再次执行前按当前渠道重新预览。远程链接素材须先保存到本机；缺失文件、损坏格式、循环依赖阻止导入，不上传模板或素材到服务器。
- 生图历史勾选批次→「比较勾选批次」，或画布选中图片／视频→「比较所选结果」：并排查看结果、原始提示词和实际参数，保留来源，旧结果标注快照不完整。展示只读，不裁剪历史或修改主图。
- Composer 与工作流各步骤预览的「报价与耗时」：用户填写有来源的单价、币种和计价单位。精确匹配渠道、模型、实际参数与参考数量；图片数量改变重算费用。视频每秒费用只使用实际输出时长参数。没有对应报价不展示金额，单位不统一转换，不调用报价服务。
- 耗时统计来自成功工作台完整批次、视频完成与工作流步骤。包含等待和本地保存，同条件及张数显示中位数和样本数，失败／部分成功不统计；不补录旧日志、不自动裁剪历史。可主动清空，统计不是完成时间保证。

## 工作流节点扩展

- 文本、图片、视频、音频配置使用同一预览与执行入口。文本调用数包括备选数量，系统提示词与推理强度固定；语音合成固定音色、格式、语速与说明。文本读取文字／图片，音频只读取文字；适配器不会发送的引用在预览时拒绝。Gemini 音频和自定义调用脚本仍不执行。
- 分组展开为组内可引用素材，插件 resource 固定为普通图片／视频／音频／文字输入。预览后修改原节点、分组成员或卸载插件，不改变批准素材，也不覆盖原画布。依赖只读取主图／主文本，不展开为多次下游调用。
- 文本部分失败保留全部槽位和成功内容，下游停止。节点提供「重试未成功文本」，每次点击只补一个失败项；成功后核对结果继续。输入、参数和 Agent 来源保留；渠道、接口格式、模型能力或脚本变化要求重新预览。刷新不会重复提交。
- 四模式模板携带白名单参数，ZIP 可携带音频原始文件并分配独立 audio: 身份；本机模板和 ZIP 都不携带旧 Agent 消息身份。展开后可编辑并重新预览。文本报价只接受每次完成的固定报价，不推算 token 用量。
