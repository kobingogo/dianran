# 多页面冲突保护

所有新页面读取数据后都能直接编辑和生成，无需取得编辑权。本轮只改变浏览器同源页面的保存与清理，不增加生成超时、重试、并发或历史保留上限，也不实现团队协作。

## 保存规则

- 使用页面读取/上次提交的快照作为基线，在 IndexedDB 单个读写事务中比较最新数据并写入。独立画布、素材、任务、模板等按 ID 合并，独立草稿作用域分别合并；下一次保存仍按本页实际提交内容比较，不因第一次合并就把另一页面的新记录当作本页删除。
- 同一业务记录的并发编辑，以及删除与编辑冲突，不按时间戳决定胜负。停止覆盖，将基线、本页内容和另一页面内容保存到 `write_conflicts`；保存失败和原图保护继续有效。
- 冲突提示可下载本页冲突数据。画布和素材支持将本页修改另存为独立副本并刷新；另一页面的记录保留，删除冲突不删除对方新内容。副本不继承原节点的活动生成身份，原任务仍归属原项目。
- 本页继续编辑时保存队列保留最新快照；未处理冲突的整份快照不能误报已保存。原有画布/素材抢救 ZIP 仍可导出。冲突 JSON 保存业务快照而非原图文件，文件仍在本浏览器中；跨浏览器转移作品应使用既有 ZIP 导出。
- 不自动刷新或覆盖另一页面正在编辑的草稿和画布。要看到其他页面的新记录，可刷新读取；冲突处理按钮刷新前明确提示检查其他未保存操作。
- 任务恢复的“待确认”显示不随新增任务回写覆盖另一页面的活动回执。恢复只查询原任务，保护不新增模型调用。

## 媒体清理

新文件写入前在 IndexedDB 持久登记保护；业务记录成功保存后，同一事务解除该文件的待保存保护。保存失败的文件和冲突备份引用保留，没有按时间自动过期。

创作页面持有共享的媒体清理保护，不限制编辑。清理尝试临时取得独占资格：还有其他页面打开就跳过；只有当前页面时，持久引用扫描与文件删除共用事务，其他保存不能插入检查与删除之间。损坏的画布、草稿、模板、历史或冲突备份中止删除。不支持 Web Locks 时继续创作，但暂停自动清理以保留文件。

## 验收

39 项针对性自动化通过，覆盖独立记录并发新增/编辑、后续保存不丢另一页面数据、同记录与删除冲突、真实 localforage 代理入口及各页备份隔离、任务身份合并、画布/素材副本、媒体保护解除、跨页清理、损坏数据拒绝删除，以及 WebDAV 同步与备份恢复回归。使用 `fake-indexeddb` 的隔离事务数据，不接触用户浏览器作品；模拟锁验证不能代替真实浏览器双页验收。

请在两个真实标签页验证：

1. 分别修改不同画布，保存后第三个页面读取应同时保留；之后继续修改第一张画布，第二张不消失。
2. 修改同一画布，后保存的页面应提示冲突；另存副本后，原画布和本页副本都存在且能打开。
3. 一页删除素材、另一页修改该素材，不应静默覆盖；其他素材与文件保留。
4. 不同画布输入独立保存；同一工作台同时改提示词应保留冲突，预览历史不改变草稿。
5. 两页创建生成任务后刷新，任务身份均保留，不会自动重提。保存失败只能重试保存或查询原任务。
6. 另一页保留未保存作品时，清理不删除文件；关闭其他页面后，确实无引用且无待保存保护的文件才可清理。

本轮未执行构建、类型检查或真实付费生成；真实标签页、移动浏览器与用户作品仍待验收。
