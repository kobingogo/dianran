# Skill 安装、资源与版本

本轮在现有 Codex 原生技能加载和 `/` 调用上增加完整目录安装。源码已实现，需配套更新前端与本机 Canvas Agent；正式站点及 npm 旧版不包含本轮新增接口。

## 使用

连接本机 Agent，打开「技能」→「安装」，粘贴公开 GitHub 仓库、目录或 SKILL.md 链接。仓库含多个技能时选择目录；分支名含 `/` 时在「分支或提交」字段明确填写完整名称。审阅名称、固定提交、全部文件、文本内容、SHA-256 和声明的依赖，再确认安装。二进制素材原样保留，不执行安装脚本、不自动安装依赖、不扩大 Agent 文件或网络权限。

完整技能目录写入本机 Agent 实际工作空间的 `.agents/skills/<name>/`；不写入个人、系统或管理员技能目录。脚本的可执行位保留；仓库根许可证在子目录技能内保存为 `repository-LICENSE` 等对应名称，保留来源说明。技能包必须符合当前 Skill 入口和界面元数据校验。符号链接、子模块、路径穿越、不完整清单与摘要不符均停止，不安装部分包。GitHub 自身请求额度或资源限制可能导致读取失败，界面显示原因；未新增自动重试、下载大小或文件数上限。

安装成功后刷新技能列表，通过「使用」或输入框 `/` 选择，沿用 Codex 的结构化 Skill 输入。安装不代表已执行，读取配置不代表真实生成通过。缺少已声明命令或环境变量的点染专属技能会提示缺项并阻止提交；MCP、账户权限、脚本运行环境和未声明依赖仍标明待验证。检查只读取工具存在性和环境变量是否设置，不运行命令、不返回变量值。

## 资源和更新

点染专属技能提供「资源与版本」：查看目录与文本，编辑参考文档和脚本，新增文本、上传二进制资源、删除资源。SKILL.md 与 agents/openai.yaml 沿用技能正文编辑器，来源记录不可由界面修改。新上传的同名文件拒绝覆盖；资源变更也参与整目录修订号，其他窗口或外部编辑器修改后旧请求停止，重新加载再操作。

「审阅远端更新」展示新增、修改和删除文件，确认后使用审阅的固定快照，不再次下载远端最新内容；更新会替换完整目录，因此需要审阅本地修改。当前目录先完整备份到工作空间 `.dianran-skill-history/<name>/<revision>/`，再切换新目录；失败时恢复原目录。版本列表允许确认回退，回退前保留当前版本。历史备份不在 Codex 技能发现目录内，不自动删除或按数量裁剪。删除技能会删除当前完整目录及其中素材，更新历史仍留在本机备份目录；本轮不提供已删除技能的一键恢复。

安装审阅只暂存在本次 Agent 进程内；取消会释放快照，服务重启后需重新审阅。不会把未确认安装排入后台队列。多页面变化沿用 skills_changed 广播，切换连接或断开后迟到响应不重新打开编辑器。

后续仍保留：跨平台网络搜索与技能推荐；对真实高频任务适配产品海报、参考图分析和批量交付技能；可查看、可编辑、可删除、经用户确认保存的品牌/创作偏好记忆。本轮不自动提炼记忆、不扫描本机目录、不把任意 Skill 直接变成工作流节点。创作技能调用已有点染 MCP 工具，多步骤生成进入已有工作流审阅。

GitHub 文件清单和固定对象读取使用官方 [Git Trees API](https://docs.github.com/en/rest/git/trees) 与 [Git Blobs API](https://docs.github.com/en/rest/git/blobs)。
