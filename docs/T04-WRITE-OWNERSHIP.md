# T04：同源单页面编辑权

同一 origin 的所有画布共用一个 Web Locks 排他锁。锁随页面关闭由浏览器释放，不使用租约、超时抢占或自动强制接管。支持提供 `navigator.locks` 的安全上下文浏览器（HTTPS 或 localhost）；缺失能力时只读展示，明确提示换用支持该能力的浏览器。

只有完成权威数据重读的持锁页展示完整编辑器。其他页面展示专用只读浏览页，可以查看画布、素材、草稿、历史和模板，下载项目备份与数据清单；不挂载生成恢复、Agent、同步或编辑器副作用。存储写入、业务 store 动作、生成 API、媒体上传/删除及同步入口另设保护，不能仅靠按钮禁用。

只读页点击「在此页编辑」尝试非阻塞获取锁；锁仍被占用时继续只读。编辑页点击「保存并释放编辑权」：存在进行中的生成、上传、导入或同步时拒绝释放；否则先卸载编辑器，保存画布、素材和草稿并等待存储操作完成，成功后释放。失败保留锁、内存编辑与错误信息，支持重新保存。不会远程要求其他页强制交出锁。

新持锁页在开放编辑前重新读取所有持久化 store、模板；历史页面重新挂载并从 IndexedDB 读取，不沿用旧页面列表。Agent 输入从新草稿恢复，旧工作流提案和待执行指令清空，避免内存状态回写旧输入。读失败时仍保持只读，释放锁，不覆盖原始数据。只读浏览数据是快照，刷新按钮重新读取，不声称实时同步。

所有 localforage 实例在启动导入业务模块前安装写入屏障；只读和准备期间拒绝数据库修改。持久化 store 的只读 hydration 不产生写入；草稿保存使用可等待队列。释放时保持锁直至写入完成。新文件仍受 T01 的会话保护，清理只能由持锁页执行。
