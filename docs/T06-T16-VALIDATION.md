# T06 / T16 实现与验收

## T06 插件与脚本

- 远程安装、本地首次启用和更新先下载，展示来源、源码字符数、SHA-256、更新前后摘要以及完整源码；用户取消时不 import、不调用工厂、不运行 setup、不写安装记录。
- 本地目录发现只下载，不运行 disabled 插件的模块。启动与再次启用使用已授权源码快照并核验摘要；未经授权的记录不会自动执行。源码快照可以在管理器查看；本地插件也可以审阅更新。
- 模型 `http` GET/POST 默认凭据绑定渠道 origin 和路径段范围，跨站、路径越界不自动带 Key；显式 headers 仍由脚本作者控制。默认凭据请求使用 Axios fetch adapter 拒绝自动重定向，避免离开范围后泄露 Key。原始 `request` 不自动带凭据。
- 编辑器、授权弹窗与插件开发说明明确高权限。开发者主动配置的 `VITE_DEV_PLUGINS` 继续自动执行；不宣称脚本和插件有沙箱、签名或动态依赖审核。

## T16 提示词统计

- 业务队列存入 localforage，稳定批次身份在发送前持久化。新发生的交互与在途批次分离；只有服务端明确返回匹配身份的 accepted 回执才删除批次。
- 删除 sendBeacon 的虚假成功路径；失败、拒绝、响应丢失保留身份，沿用原 20 小时 / 40 事件发送触发，未新增自动重试周期。
- 客户端按既有 60 个 ID / 每种计数 30 的服务端边界分批，超出部分保留。API 私有 Blob 按 batchId 排他写入，同一身份/不同内容返回冲突；失败不伪造成功。
- 聚合器写入已接受身份后再删除原批次；原批次删除失败或迟到重发不会再次计数。身份不按数量或时间裁剪，既有每日明细保留规则不变。内容筛选、发布门禁与评分公式未改。
- 前端探测 API 协议 2；静态页面、停用或旧协议明确标记不可用，停止该页面会话后续上报。提供 `getPromptUsageStatus` 与 `subscribePromptUsageStatus` 给展示层读取。
- 仅上传内置素材 ID、复制/应用次数、UTC 日期和随机批次身份，不上传创作提示词、文件、Key 或用户标识。交互数据不完整，不代表生成成功和作品质量。
