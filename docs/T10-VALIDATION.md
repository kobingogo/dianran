# T10 WebDAV 冲突与写入保护验收

开发已落地，真实 WebDAV 服务、多设备和浏览器验收待用户确认。本项未发布、部署或合并主分支。

## 已实现

- 同步入口先提交当前画布快照，再等待画布、素材、草稿保存队列；本地写入失败时停止同步。使用 T04 编辑权保护，不释放锁、不自动重试。
- 同步前在浏览器 IndexedDB 的 `webdav_sync_backups` 保存画布、素材、生成记录和它们引用的 Blob。备份直接携带媒体，因此普通媒体清理不会使备份缺图。没有自动按数量或时间裁剪备份。
- 设置页提供“恢复同步前备份”。恢复前再次备份当前状态，远端不变。恢复成功后重新加载当前页面，确保画布内存不再沿用恢复前内容；不同媒体内容会分配新 key，仅复用同摘要文件，不覆盖未恢复的草稿引用。恢复失败保留两份备份以便救援。
- 每次同步用随机测试资源验证 `If-Match` 和 `If-None-Match` 的实际拒绝语义，并尝试清理该测试资源；条件机制不可用时停止同步。服务不支持删除或忽略条件头时可能留下 `.dianran-condition-*` 测试文件，提示中说明这一点。
- 存在的清单必须取得强 ETag，上传发送 `If-Match`；不存在的清单发送 `If-None-Match: *`。服务或 CORS 未提供强 ETag 时阻止无保护覆盖。本地配对代理已允许浏览器读取 ETag 响应头。
- CAS 校验失败重新读取远端，展示两侧独有数量及内容变化的记录名称；停止该域写入，不自动重试、不把过期合并结果套到本地。
- 无共同祖先时保守处理同 ID 内容差异：保留本地记录和具有新 ID 的远端副本，不依赖设备时钟选择一方。删除与编辑冲突保留原 ID 的删除标记，以及具有独立项目 ID 的作品副本。
- 媒体内容相同才共享；同 storageKey 的 Blob 内容不同则为远端分配新 key 并改写其引用。远端上传文件使用 SHA-256 内容地址，避免覆盖另一个版本的媒体。
- 分域使用真实完成回执，汇总已完成与未完成域。远端清单已写入但本地持久化失败，或同步期间本地又有修改时，明确报告远端已写入与本地未完成，不覆盖新编辑、不显示全量成功。仅全量成功更新“上次同步”时间。

## 可复现检查

在仓库根目录运行：

```bash
node --test web/tests/app-sync.test.mjs
```

13 项行为检查通过：

1. 不同节点内容与时钟偏差保留双方；相同内容仅键顺序不同不会重复。
2. 删除与编辑保留删除标记和独立作品。
3. 本地 flush、含 Blob 的备份先于远端写入；首次同步使用 create-only 条件。
4. 本地保存失败、条件机制不可靠时不写清单。
5. 弱 ETag 拒绝受影响域，其他域给出可靠完成状态。
6. CAS 竞态重新读取差异；不自动重试、不应用过期结果。
7. 相同 storageKey 的不同 Blob 双方保留，上传媒体采用内容地址。
8. 上传中断给出部分结果；同步期间本地编辑保留。
9. 原媒体被普通清理移除后，仍能使用独立备份恢复，并保存恢复前状态。
10. 请求发送真实条件头，能力探测校验拒绝响应。
11. 通过真实 HTTP 服务及配对代理获取 ETag、条件写入；旧 ETag 写入被拒绝且服务内容保持最新版本。
12. 存储媒体的临时地址不产生虚假冲突，普通文本中的 blob 字符串仍比较。
13. 恢复不同内容的媒体重新分配身份，不覆盖未恢复草稿中的媒体。

测试使用隔离的内存业务存储和本地 HTTP 测试服务，没有接触用户 WebDAV 或作品，没有付费 API 请求，没有执行构建、类型或语法检查。

## 用户待验收

- 在实际服务确认支持条件 PUT，直接访问时 CORS 暴露 `ETag`；经配对代理时复测相同流程。无条件支持的服务应明确停止，不能显示成功。
- 两设备先共享一个项目，分别修改不同节点、相同节点后依次同步，确认副本内容完整并能导出；调整设备时间后结果仍不依赖时间戳裁决。
- 一侧删除、另一侧编辑后同步，确认删除标记和编辑副本均保留。
- 模拟另一个设备在上传期间更新清单，确认错误中出现重新读取的差异，远端未被覆盖；用户明确检查后再次同步。
- 实际大图/视频、服务断连、QuotaExceeded 和浏览器中途关闭后的恢复；确认分域提示与备份能还原。
- 确认恢复成功后当前页面自动重载，节点、生成记录和媒体可读取，继续编辑不会覆盖已恢复结果；确认恢复不更改远端及未恢复的草稿媒体。

没有 CRDT、协作账户、三方自动裁决或后台同步。保守策略可能产生额外副本；此成本优先于在时钟偏差或缺少共同祖先时丢失作品。备份主要保存在当前浏览器来源下，尚不等于云备份，清除站点数据也会删除它们。
