## 可测试变更

- 五个首页模板均支持填写内容后“创建画布并审阅工作流”，不自动调用模型；剩余三个是故事分镜、情绪板和社媒封面。
- 工作流接入文本、图片、音频和视频，按模式核验模型、参数和引用范围。上游结果成为后续步骤的冻结输入；不支持的输入在预检中拒绝。
- 图片/视频参数预设独立保存，应用时重新核验参数，不存储 API Key。
- 本机模板 ZIP 包含原媒体文件，导入重新分配文件身份；完整性验证在写入任何媒体前完成，拒绝缺件、篡改、重复身份和不合法依赖。
- 原 PR 模板 ZIP 缺少文件摘要，本轮补入大小与 SHA-256 验证。该格式尚未正式发布，不增加旧格式兼容。
- 批次与版本比较接入画布和图片历史；比较不改变采用状态。图片识别使用来源加结果身份，避免不同版本同一图片 ID 显示错误文件。
- 来源报价和匹配条件下的本机耗时中位数接入预览；没有真实报价或样本时不虚构金额/时长。
- 新增预设、估算与模板导入沿用单编辑页写入保护；已有保存失败、结果未知、视频原任务查询和审批保护继续保留。
