## 可复现脱敏工具与开发者检查

`node scripts/acceptance/redact-record.mjs 原始记录.json 脱敏记录.json` 读取本地记录，以字段白名单输出；输出文件必须不存在，权限为 0600。不发起网络请求、不执行生成、不读取浏览器 Key。保留模型/参数等字段仍需人工检查，确保没有误把秘密填写进普通字段。

输入包括 `mode`（image/video/text/audio/agent/mobile/docker）、`state`（not-run/pending/success/failure/unknown）、`baseUrl`、`model`、`browser`、`device`、`gitCommit`、身份字段、`parameters`、引用/输出/POST/查询次数和 `mediaRestored`。工具不复制提示词、系统提示词、headers、请求/响应正文、文件、完整 URL 或原始身份；来源只留 origin。工具不会据缺失信息生成通过结论，其输出标注为用户提供且需复核的记录。
