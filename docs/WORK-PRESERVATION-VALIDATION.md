## T01 的实现范围

- 图片与媒体清理读取同一组权威引用：磁盘素材、画布（包括运行快照）、Composer 草稿、工作流模板、图片与视频生成历史，以及调用方提供的当前内存内容。
- 保留磁盘和内存引用的并集，避免列表删除尚未落盘、画布尚未加载或保存失败时清理原文件。
- 任一权威来源读取失败、顶层结构损坏或历史记录格式错误时拒绝生成保留清单，停止删除。后台清理失败写入诊断日志，不产生未处理的异步异常。
- 新上传或导入的图片、视频、音频在当前页面会话内不参与自动清理；页面刷新后重新按业务引用判断。此策略暂时多保留未采用文件，避免提交间隙误删，不引入清理时间或大小阈值。同源互斥已由 T04 补齐。
- 正常清理媒体时同步释放该文件已缓存的对象 URL。

T01 本身不改变素材保存契约；该部分由下述 T02 实施。项目 ZIP 的缺件与完整恢复由 T03 实施。

## T02 的实现范围

- 素材列表使用既有 `canvasIndexedStorage` 的 `app_state` 存储；不再静默写入或读取 localStorage，不自动迁移旧备用列表。主题等小配置存储不变。
- 复用现有保存队列，串行写入并保留最新失败快照。新增、修改、删除、替换返回实际写入回执；保存失败保留当前页面内容。排队延迟仍沿用既有数值，没有新增重试次数、超时或大小限制。
- 素材读取失败、数据损坏或版本未知时，不将空列表写回磁盘，所有业务修改入口拒绝执行；再次读取不能丢弃尚未保存的修改。
- 提示词页、来源弹窗、工作台、画布节点和侧栏使用统一保存反馈；Agent 工具添加素材及 WebDAV 同步也等待回执。批量上传/导入失败时保留已写入或仍在内存的条目，提示查看素材并重试，不声称全部完成。
- 「我的素材」和画布素材侧栏显示读取、保存、失败状态；失败提供「重试读取/保存」，写入失败还可「导出抢救包」。编辑弹窗等待保存，已进入内存的失败新增由状态栏重试，避免再次提交表单重复添加。
- 删除保存失败不启动媒体清理；重试成功后才启动清理。未保存内容离开页面时触发浏览器原生离开提醒，页面隐藏时尝试保存。
- 素材抢救包保存当前列表和可读取的直接原文件，并记录缺失或读取失败文件、附带范围说明。存在缺件的普通素材导出拒绝下载；含缺件的抢救包拒绝当作正常素材包导入。抢救包不是完整站点备份，不保证远程资源或 metadata 中创作过程媒体已经打包；不包括画布、草稿、模板、历史与配置。

## T03 的实现范围

- 项目备份包升级为 **v4**，包含完整/抢救模式、缺失清单、未打包媒体链接，以及原文件大小和 SHA-256 摘要。浏览器项目存储格式不变；旧版 ZIP 与未知格式拒绝导入，不做兼容迁移，已有项目需使用当前版本重新导出。
- 导出冻结当前项目快照，递归核对节点、备选图片、对话引用、创作输入和运行快照中的原文件身份。编辑页导出包含当前节点、连接与尚未延迟保存的视口，不以磁盘保存成功作为导出前提。
- 原文件缺失、读取失败、无原文件身份的临时媒体或未打包的远程媒体不能下载为完整备份。界面列出具体问题，可由用户主动选择导出项目结构和可用文件的抢救包；不自动请求远程媒体。
- 普通导出同时检查基本项目结构、节点身份和连接引用。项目卡片、批量导出、编辑页和保存失败出口使用统一反馈；保存失败出口直接标明「导出抢救包」。
- 导入先校验整个 ZIP 的应用/版本、项目结构、节点与连线、文件身份与路径、大小、摘要和引用覆盖，再写入媒体。损坏或漏件不能靠本机恰好已有同名文件蒙混恢复。
- 导入媒体生成新身份，递归重建引用与本页对象 URL；项目也经现有导入入口生成新项目身份，不覆盖原画布或同名文件。共享引用仍指向同一份新文件。
- 抢救包必须在界面确认后才恢复可用内容，显示缺失清单并使用警告反馈；缺失文件身份也重建且不指向已有用户媒体。媒体写入失败只回收此次暂存文件；项目进入内存后保存失败则保留文件和项目，供重试或再次抢救。
- 本次完整备份仅指所选画布及声明的媒体，不等于整个站点备份；说明文件明确不包含素材列表、Composer 草稿、模板库、画布以外的生成历史和 API Key。
- 草稿 PR 的模板 ZIP 已拒绝缺失原文件并重建导入身份，完整性含义一致；没有改动未合并的模板实现。项目导出 v4 和模板 ZIP v1 独立管理，模板功能实际验收仍按 PR 整合推进。

导出与校验均使用现有 ZIP 库和平台加密 API，没有新增超时、重试、并发或文件大小边界。跨页写入与清理竞争由下述 T04 补齐。

## T04 的实现范围

- 设计先行，见 [同源单页面编辑权](T04-WRITE-OWNERSHIP.md)。使用浏览器 Web Locks，不使用租约、超时或强制抢占。
- 业务模块导入前安装 localforage 写入屏障，覆盖所有实例。使用 Proxy 保持保护，避免 localforage 驱动初始化替换方法后绕过屏障；未支持或锁调用被拒绝时明确只读。
- 持锁页完成持久化 store 和模板重读，恢复最新 Agent 草稿并清空旧工作流提案、未执行指令后才挂载编辑器；其他页面只挂载独立浏览器，可浏览项目节点、素材、草稿、历史与模板，下载元数据清单、素材和项目备份。不挂载 Agent、生成恢复或同步副作用。
- 画布、素材、Composer、模板、插件 store 业务动作，以及生成 API、上传、删除、导入和同步入口另行保护。只读 hydration 只更新读取快照，不写回数据库，不在后台补缩略图。
- 正常交接捕获画布最新节点和视口，卸载编辑器后等待画布、素材、草稿及存储回执；保存失败保留锁与内存编辑。Agent、生成、上传、导入或同步尚在执行时拒绝交接。未解决的写入失败不允许交出编辑权。
- 草稿沿用保存队列并立即 flush，保持即时保存，不新增排队延迟；失败快照保留，未保存时关闭页面提醒。新文件仍由 T01 会话保护，上传与清理竞争不删除未完成提交文件。
- 主页面关闭由浏览器释放锁；只读页主动点击「在此页编辑」，先重读权威状态再编辑。只读快照可刷新，不宣称实时同步，也不自动抢占其他页。

## 用户验收

1. 在独立测试画布生成或导入视频，将视频留在工作台历史中，删除无关素材，刷新后确认历史视频可播放、下载。
2. 让图片或媒体只被草稿、模板、运行快照引用，删除其他素材，刷新后确认引用仍可使用。
3. 在测试环境模拟历史或模板读取失败，确认原文件不减少，控制台有停止清理说明。
4. 上传或导入文件后，模拟业务记录保存失败，同时触发清理，确认当前页原文件仍可打开；到素材状态栏重试保存，刷新后确认记录恢复。
5. 用构造的无引用旧文件验证清理仍可删除；本页新文件预期保留，刷新且无业务引用后才可清理。

6. 分别从提示词、图像/视频结果、画布节点、侧栏和素材导入入口保存；模拟一次 IndexedDB 写入失败，确认没有成功提示，内存内容保留，重试后刷新可读到最新列表。
7. 模拟素材读取失败或未知版本，尝试新增、删除、导入和 WebDAV 同步，确认原记录未覆盖；恢复读取后才允许写入。
8. 保存失败时导出抢救包，检查当前未保存文本和可读取原文件已打包，缺失文件列在清单；缺件抢救包不可误报为完整导入。
9. 编辑弹窗保存期间按钮等待；失败新增关闭表单后用状态栏重试，不重复创建素材；未保存时关闭页面应出现浏览器原生提醒。
10. 导出含图片、视频、音频、创作输入和运行快照的项目，在独立浏览器存储中导入，确认原文件可打开、下载，参数与关系一致；当前视口应保留。
11. 构造缺失原文件或仅保留远程媒体的项目，从卡片、批量和编辑页导出，确认不报完整备份成功；选择抢救导出后检查模式、缺失与远程清单。
12. 导入抢救包时取消确认，不应写入文件或项目；确认后只恢复可用内容，不得把缺件绑定到本机已有同名媒体。
13. 修改包内一个文件、删去原文件、伪造清单或使用旧版 ZIP，确认在任何业务写入前拒绝；媒体写入失败只清理新文件，项目保存失败后仍可重试或抢救。

14. 同源开两个页面，A 编辑两个不同画布及素材；B 只读浏览。A 保存并释放后 B 接管，确认列表、草稿、历史与模板以重读结果为准。
15. 模拟保存失败，确认 A 保留编辑权与修改、B 无法接管；A 重试保存后可正常交接。生成/上传/Agent 正在执行时不能释放。
16. 不支持 Web Locks 或无法建立锁的浏览器明确只读；关闭 A 后 B 可取得编辑权，刷新持锁页后状态仍可解释。
